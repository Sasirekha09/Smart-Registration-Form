# Smart Registration Form

A responsive and interactive registration form built using **HTML, CSS, and JavaScript** with real-time form validation.

## 📌 About the Project

The Smart Registration Form is a beginner-friendly web development project designed to validate user input and provide instant feedback.

It checks the user's Name, Email, Password, and Bio fields before allowing form submission.

## ✨ Features

- **Name Validation:** Checks whether the name field is empty.
- **Email Validation:** Validates the email format.
- **Password Validation:** Ensures the password contains at least 6 characters.
- **Bio Validation:** Ensures the Bio field is not empty.
- **Character Counter:** Displays the number of characters entered in the Bio field (maximum 200 characters).
- **Real-Time Validation:** Displays validation messages while the user types.
- **Submit Button Control:** Enables the Submit button only when all fields are valid.
- **Success Message:** Displays a registration success message after successful submission.
- **Responsive Design:** Simple and clean user interface.

## 🛠️ Technologies Used

- HTML5 – Structure of the registration form.
- CSS3 – Styling and responsive design.
- JavaScript – Form validation and interactive functionality.
